## Fiverr gig

### Title
I will clean, format, and remove duplicate rows from your CSV or Excel data

### Category / search terms
Data Processing; Data Cleaning; Python; CSV; Excel; Automation

### Description
Do you have a messy CSV file with duplicate rows, inconsistent spacing, or empty records?

I can help clean and organize your data using a Python automation script.

**What I can provide:**
- Remove exact duplicate rows.
- Clean extra spaces in text fields.
- Remove completely empty rows.
- Count missing values in each column.
- Deliver the cleaned CSV file.
- Include a short summary report.

**What I need from you:**
- A sample of your CSV file.
- The cleanup rules you want followed.
- Your preferred output format.

Your original file will be kept unchanged. I will not guess or invent missing information.

Please contact me before ordering if your file has special formatting or complex cleanup rules.

### Starter package suggestion
One small CSV file, up to 500 rows, basic whitespace cleanup, exact duplicate removal, and a summary report. Set a modest introductory price that meets Fiverr's current minimum and reflects the time required.
